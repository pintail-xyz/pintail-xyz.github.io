# Project goal

A full migration of my website to Quarto. It is hosted on github pages and currently uses Jekyll and the Minimal Mistakes theme.

# Resources

A copy of the static site is saved in ~/dev/pintail-xyz.githhub.io_archive.

# Instructions

- Please use the Yeti theme from Quarto, but customise the colour scheme with inspiration from the colours of a Pintail duck
- I'm going for a minimalistic look. I don't think I need the category tags on articles for example (I think there are less than 20 articles in total anyway)
- Migrate all existing content, but in the old version of the site the file structure got a bit messy - please use a consistent/logical file structure in the new version
- I had to use some hacky solutions to get things to display properly with Jekyll due to my use of code, charts and formulae. Please keep any eye out for this and highlight anything which may not display well in the new version of the site.
