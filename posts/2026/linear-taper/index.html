A Linear Issuance Taper: Simpler Formula, Wider Anti-Discouragement Range

Replacing the quadratic weight with a linear one gives r_net(f) = (1−u)·r₆₄(f) — a simpler taper that reaches zero at 50% staking, requires a smaller BASE_REWARD_FACTOR adjustment, and preserves the aggregate anti-discouragement property up to f ≈ 17% rather than 10%.
Published

May 17, 2026

The previous post showed that pairing a quadratic blending weight with a quadratic staking offset yields a net consensus-layer yield of:

\[r_\text{net}(f) = (1-u)^2 \cdot r_{64}(f), \qquad u = f/f_\text{sat}\]

where \(r_{64}(f) = B \cdot E / \sqrt{f \cdot S \cdot 10^9}\) is the existing formula with \(B = 64\), \(E \approx 82{,}181\) epochs per year, and \(S \approx 120.5 \times 10^6\) ETH. The same algebraic cancellation works for any polynomial weight. This post applies it to the linear case, \(w(u) = 1-u\), and examines the differences.

Construction

For any weight function \(w(u)\) satisfying \(w(0) = 1\) and \(w(1) = 0\), define:

  • Gross yield (blended): \(\tilde{r}(f) = r_\text{sat} + w(u)\bigl[r_{64}(f) - r_\text{sat}\bigr]\)
  • Staking offset: \(\delta(f) = \bigl[1 - w(u)\bigr] \cdot r_\text{sat}\)

where \(r_\text{sat} = r_{64}(f_\text{sat}) \approx 2.14\%\) is the current yield evaluated at saturation. Subtracting the offset:

\[r_\text{net} = \tilde{r} - \delta = r_\text{sat}\,w(u) + w(u)\,r_{64}(f) - w(u)\,r_\text{sat} = w(u)\cdot r_{64}(f)\]

The \(r_\text{sat}\) terms cancel for any choice of \(w\). For the linear case \(w(u) = 1-u\):

\[\boxed{r_\text{net}(f) = (1-u)\cdot r_{64}(f)}\]

The blending constant \(r_\text{sat}\) disappears from the final formula entirely — no new protocol constant is needed beyond STAKING_SATURATION_INCREMENTS.

Yield

Properties

Zero at saturation

At \(f = f_\text{sat}\) (\(u = 1\)), the factor \((1-u)\) vanishes and \(r_\text{net} = 0\) exactly.

Kink at saturation

The slope of \(r_\text{net}\) with respect to \(f\) at saturation is:

\[\left.\frac{dr_\text{net}}{df}\right|_{f=f_\text{sat}} = -\frac{r_{64}(f_\text{sat})}{f_\text{sat}} = -\frac{r_\text{sat}}{f_\text{sat}} \neq 0\]

The net yield arrives at zero with a finite negative slope — a kink. The quadratic weight \((1-u)^2\) produces a zero derivative at saturation (smooth pinch-off) because it provides an extra factor of \((1-u)\) that vanishes there. The linear weight has no such factor, so the kink is unavoidable within this family.

Per-validator anti-discouragement

\(r_\text{net}(f) = (1-u)\cdot r_{64}(f)\). Both \((1-u)\) and \(r_{64}(f) \propto f^{-1/2}\) are strictly decreasing in \(f\); their product is therefore strictly decreasing throughout \(f \in (0, f_\text{sat})\). Individual validators always earn more when total staking is lower.

Aggregate anti-discouragement

Net annual issuance is \(I_\text{net}/S = (1-u)\cdot r_{64}(f)\cdot f \propto (1-u)\sqrt{u}\). Differentiating with respect to \(u\):

\[\frac{d}{du}\bigl[(1-u)\sqrt{u}\bigr] = \frac{1-3u}{2\sqrt{u}}\]

This is positive for \(u < 1/3\), i.e., \(f < f_\text{sat}/3 \approx 16.7\%\). Below that threshold, forcing validators offline shrinks the total reward pool — the standard anti-discouragement result. Above \(f \approx 17\%\) the aggregate property no longer holds, but this threshold is wider than the \(f_\text{sat}/5 = 10\%\) threshold of the quadratic formula.

The linear formula is strictly simpler — the calibration factor \(B'\) is much closer to the current value, and the spec implementation requires one fewer integer multiply — at the cost of a kink rather than a smooth pinch-off at saturation.

Calibration

The formula \(r_\text{net}(f) = (1-u)\cdot r_{B'}(f)\) inherits the current BASE_REWARD_FACTOR \(B_0 = 64\). Replacing it with \(B'\) scales all yields and issuances uniformly. At today’s staking ratio \(f_0 \approx 1/3\) (\(u_0 = 2/3\)), the taper factor is \((1-u_0) = 1/3\); matching the current gross yield requires \(B' = B_0 / (1-u_0) = 3 \times 64 = 192\). The next round value is \(B' = 256\) (scale factor 4).

\(B' = 192\) matches both the current yield and the current issuance rate at today’s staking ratio exactly, making it a natural deployment calibration: validators see no immediate change in rewards at launch.

Spec Implementation

The implementation replaces get_base_reward_per_increment with a version that multiplies the current result by the integer approximation of \((1-u) = \texttt{deficit} / \texttt{STAKING\_SATURATION\_INCREMENTS}\):

def get_base_reward_per_increment(state: BeaconState) -> Gwei:
    total_active_balance = get_total_active_balance(state)
    total_increments = total_active_balance // EFFECTIVE_BALANCE_INCREMENT
    if total_increments >= STAKING_SATURATION_INCREMENTS:
        return Gwei(0)
    current = Gwei(EFFECTIVE_BALANCE_INCREMENT * BASE_REWARD_FACTOR
                   // integer_sqrt(total_active_balance))
    deficit = STAKING_SATURATION_INCREMENTS - total_increments
    return Gwei(deficit * current // STAKING_SATURATION_INCREMENTS)

This adds one integer multiply and one integer divide to the existing formula. The quadratic implementation requires an additional squaring step (d_sq = deficit * deficit), making the linear version marginally simpler. All downstream calculations — participation rewards, inactivity penalties, slashing — consume the adjusted base reward without further changes.

The only new constant relative to the current spec is STAKING_SATURATION_INCREMENTS, the total active balance at the saturation point expressed in EFFECTIVE_BALANCE_INCREMENT units. BASE_REWARD_FACTOR is updated from 64 to the chosen \(B'\).

Summary

The linear taper \(r_\text{net}(f) = (1-u)\cdot r_{64}(f)\) is the simplest member of the blend-and-offset family:

  • Net issuance reaches zero at \(f_\text{sat} = 50\%\) staked, with a kink (non-zero derivative) at that point.
  • The per-validator anti-discouragement incentive is preserved throughout the full staking range.
  • The aggregate anti-discouragement property holds for \(f < f_\text{sat}/3 \approx 17\%\), a wider range than the quadratic formula’s \(f_\text{sat}/5 = 10\%\).
  • \(B' = 192 = 3 \times 64\) reproduces today’s yield and issuance rate exactly at the current staking ratio, requiring a smaller recalibration than the quadratic’s \(B' = 576\).
  • The spec change is minimal: one new constant (STAKING_SATURATION_INCREMENTS), one modified function, one updated constant (BASE_REWARD_FACTOR).
